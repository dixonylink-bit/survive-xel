# 🐟 Survive Xel

A browser platformer made with HTML, CSS and vanilla JavaScript. Xel bounces on its own, so your job is to steer it from platform to platform and reach the top without falling.

[Play the game here](https://dixonylink-bit.github.io/survive-xel/)

![Game screenshot](./assets/Screenshot%202026-11-26%20194214.png)

## 🎮 How to play

- Xel jumps **automatically**. You can't stop it from bouncing.
- Use the **⬅️ left** and **➡️ right** arrow keys to move.
- Land on the platforms to bounce higher and climb.
- Reach the **final platform** at the top to win.
- If Xel falls off the bottom of the screen, it's **game over**.
- Use the 🎵 button to turn the music on or off.

## ✨ Features

- Automatic jumping with gravity physics
- Moving and static platforms
- Collision detection
- Start, win and game over screens with a replay button
- Background music that changes on win and game over

## 🛠️ Built with

- HTML5
- CSS3
- JavaScript (ES6 classes, no libraries)
